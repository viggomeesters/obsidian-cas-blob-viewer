# Contributing

Open or reuse an issue describing expected behavior and a synthetic reproduction. Work on a branch and submit a focused PR. Run the documented local checks and include actual host evidence for rendering/lifecycle changes. Keep code compatible with the declared Obsidian API minimum, preserve settings and keep all data access inside the selected vault.

Do not add GitHub Actions. Do not commit authentic vault data, local paths, credentials or generated settings. Mark controlled mocks, actual host tests and platform coverage separately.

# Security

The plugin reads vault-relative CAS blobs and optional JSONL metadata. It does not write vault files or send telemetry. HTML/XHTML render as literal text. PDF opening delegates to the browser PDF viewer; do not open untrusted PDFs. Content hashes are identifiers, not a digest-verification guarantee.

Report a reproducible issue through GitHub using synthetic data. Do not attach authentic notes, blobs, metadata, tokens or local vault paths. For a sensitive report, contact the maintainer privately rather than publishing exploit details or private content.
